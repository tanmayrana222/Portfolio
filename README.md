# Tanmay Rana - Portfolio

Single-page portfolio built from the CV for Software Engineering, DevOps and SRE applications.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public repository** named `portfolio`.
2. Upload `index.html` and `style.css` from this folder to the repository root.
3. Open the repository **Settings**.
4. Select **Pages** from the left sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. After GitHub finishes deployment, your portfolio should be available at:
   `https://tanmayrana222.github.io/portfolio/`

If you instead name the repository `tanmayrana222.github.io`, the site can be published at:
`https://tanmayrana222.github.io/`

## Local preview

Double-click `index.html` to open it in a browser.
